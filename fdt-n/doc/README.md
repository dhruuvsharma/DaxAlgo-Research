# FDT-N volume-footprint transformer

This folder is the canonical home for the FDT-N research material and frozen reviewed artifacts.

- `research/` contains the evidence ledger, full research source, and venue-neutral publication
  manuscript.
- `submission/` contains the Dhruv Sharma-authored arXiv-style LaTeX source, bibliography, and reproducible
  vector-figure generator.
- `reports/` contains the rendered research, publication, and final submission PDFs.
- `model/` contains the reviewed ONNX model, metadata, and parity fixture.

The model package exposes the four-input, one-output marginal-quantile interface documented in the
paper. Frozen metadata retain build-time lineage records from the original workspace.
