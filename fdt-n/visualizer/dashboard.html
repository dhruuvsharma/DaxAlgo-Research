What is FDT-N?

A 371,861-parameter transformer that reads the full executed-volume footprint of the last 64 one-minute bars — every traded price row with buy/sell volumes, imbalances, and auction diagnostics — and predicts, for the next 1–8 minutes, an ordered distribution (q10 / q50 / q90) over 7 market-structure targets: POC offset, low, high, buy-POC, sell-POC, relative log-volume, and delta fraction. Rows are pooled by 4 learned auction queries, fused with bar aggregates through a learned gate, passed through 3 causal temporal blocks, then decoded by 8 horizon queries with cross-attention.

Row projection → 11 features per price row become 64-channel tokens

Linear → GELU → Linear → RMSNorm for each of the up-to-187 price rows per bar. Heat map below: rows (price levels, high→low) × channels for the selected bar; padded rows are grayed.

Auction-query pooling → each bar's rows collapse to 4 tokens

4 learned queries cross-attend over the price rows (per-bar, ragged, masked). Left: attention weight of each query over the anchor bar's rows (padded rows grayed). Right: the 4 pooled 64-channel tokens for the anchor bar.

Row summary + bar projection → fusion gate

The 4 tokens per bar are squashed to one 64-channel row summary; bar features are projected to 64 channels; a learned sigmoid gate blends them per channel and per bar: temporal = gate·row + (1−gate)·bar + projected

gate → row footprint gate → bar aggregates overlay: projected residual

Causal temporal stack → 3 × (RMSNorm · MHA · LayerScale · SwiGLU)

64-bar sequence attends only to the past. Below: head-averaged 64×64 attention for each block (row = query bar, column = key bar; strict upper triangle is masked). Brighter = more attention. Row 63 detail on the right.

Horizon decoding → 8 horizon queries cross-attend the bar memory

Two decoder blocks: horizon self-attention + cross-attention over the 64-bar memory. Left: block-2 attention of each horizon (1..8) over bars (0..63). Right: pooled attention by bar — which minutes the forecast actually reads.

Ordered quantile head → 8×7×3 numbers, guaranteed coherent

Each horizon-query vector maps to 21 raw logits, then to (median, +softplus gap, −softplus gap) per target; low = min(low, poc), high = max(high, poc), buy/sell-POC clamped inside [low, high]; delta fraction squashed by tanh. The honest comparison — pooled q50-forecast MAE on the frozen test set

Negative result, reported honestly. FDT-N beats zero-change persistence by 7.25% pooled, but the simple train-only direct ridge baseline is 2.68% better than FDT-N, winning 55 of 56 horizon-target cells. The study's claim is the architecture's viability, not superiority over simple baselines.
